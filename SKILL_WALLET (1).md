# Skill Wallet Project Entry

## Project Title
EduGenie — Google Gemini Powered Learning Assistant

## Short Description
Built an AI-powered educational web application using Python, FastAPI and Google Gemini to provide question answering, simplified explanations, automatic MCQ quizzes, study-note summarization and personalized learning paths.

## Technologies
Python, FastAPI, Google Gemini API, HTML, CSS, JavaScript, Jinja2, REST API, GitHub

## Key Skills Demonstrated
- Generative AI integration
- Prompt engineering
- Python backend development
- REST API development
- Frontend integration
- JSON handling
- Responsive UI design
- API error handling
- Software testing
- Git/GitHub project management

## My Contribution
Designed and developed the EduGenie web application, integrated Gemini-powered educational modules with FastAPI endpoints, created the responsive frontend, handled quiz JSON responses and errors, and documented the project for GitHub.

## Outcome
Created a functional student-focused AI learning assistant that can answer questions, explain concepts, generate quizzes, summarize study material and recommend a structured learning path.
